# Solving Inverse Problems with Differentiable N-Body Systems

The project is structured as follows:

- SurrogateKeplerSolver: This folder contains the experiments related to surrogate Kepler solvers.
- The following folders contain code that is taken from [this repository](https://github.com/AndreasMerrath/Solving-the-three-body-problem-with-neural-networks).
    - NormalCode: This folder contains the implementation of N-body solver.
    - TensorCode: Contains the differentiable version of N-body solver.
