# SurrogateKeplerSolver

The project is structured as follows:

- 1_data-generation.ipynb: For generating the Kepler dataset.
- 2_hyperparam_search: For performing hyperparameter search.
- 3_hyperparam_search_plot: To plot hyperparameter search results.
- 4_train_model: To train the surrogate kepler models.
- 5_trained_models_simulations: Use trained surrogate models to get simulations.
- 6_solve_inverse_problem: Use trained models to solve inverse problems.
- 7_time_taken_learn_masses: Measure the time taken to learn masses with kepler surrogate.
- 8_time_taken_learn_masses_plot: Plot the time_taken experiment results.
